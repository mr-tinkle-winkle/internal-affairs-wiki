This character is exclusive to [[Pluribus|Pluribus]] members, specifically those with the "Developer" rank.

# Functions
- Pressing F will freeze the object you are looking at.
	- Holding F and scrolling will change the 'relative timescale' of the object you are looking at.
- Pressing G will toggle gravity on the object you are looking at.
- Pressing H will 'select' the object you are looking at.
	- Holding H while not looking at the object will now allow you to 'Modify' it.
		- Pressing F will freeze the object you have selected.
		- Pressing G will toggle gravity on the selected object rather than the object you are looking at.
		- Scrolling will change the size of the selected object, and proportionally change the mass.
		- Left Click will pause the object, freezing it in place.
	- The selected object will have a highlight, visible only to this player.
