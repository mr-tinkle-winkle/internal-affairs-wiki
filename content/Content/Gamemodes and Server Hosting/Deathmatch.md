This is a mode set in either a smaller map or a limited portion of a larger map. In this mode, the players' fight against other players. 

All of the default settings are below.

- Which Characters are allowed.


All of the variations are below.

- Team Deathmatch
	- Host chooses which companies are allowed.
	- Host chooses spawn-points for each company.
	- Players can join any allowed companies.
- Champions
	- Host chooses between 1v1, 2v2, 3v3, and 4v4.
	- Host chooses if teams are random or if teams are manual.
	- Host chooses how many fights can go on at once.
